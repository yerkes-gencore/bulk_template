Sequencing data was aligned to the NCBI reference genome for Macaca mulatta (RefSeq: GCF_049350105.2)[1] using STAR 2.7.9a [2]. 
Transcript abundance estimates were calculated using the STAR '--quantMode GeneCounts' option and imported into RStudio (R v4.5.3) for analysis.

Differential gene expression analysis was performed using the packages edgeR v4.8.2 (PMID: 19910308) and limma v3.66.0 (PMID:25605792) as follows.
Count tables were filtered for low-abundance and/or low-occurrence genes (filterByExpr) and fit to a linear model (stats::model.matrix; E ~ group.timepoint etc) with subject blocked and sample.weights=TRUE (voomLmFit). Empirical Bayes statistics were calculated for the model fit (eBayes), contrasts between experimental conditions were defined (makeContrasts), and differentially expressed genes (adjusted P < 0.05) were extracted per contrast (contrasts.fit).

Gene set enrichment analysis was performed using the fGSEA R package [3] on pathways from the Hallmark, Reactome, Biocarta, Kegg (legacy), and Gene Ontology: Biological Processes collections, which were downloaded using package msigdbr v26.1.0
